# Вопросы о Пульсе

[← Страница Пульса](../README.md) · [Первый запуск](QUICKSTART.md)

## После установки нет верхней панели и дока

Открой **«Настройки и напоминания»** через значок Пульса в трее. Включи верхнюю панель и плавающий док, затем нажми **«Сохранить настройки»**. После новой установки оба выключены. При необходимости проверь выбранный экран в настройках.

## Как вернуть обычную панель Windows?

Выключи **«Плавающий док»** и сохрани настройки. Можно также выбрать **«Использовать панель Windows»** в пункте управления или меню значка Пульса. Обычный выход из Пульса тоже должен вернуть панель задач Windows.

В 0.13.4 добавлено восстановление панели перед удалением программы и при аварийном завершении. Эти изменения входят в 0.13.6. Если панель всё же не восстановилась, перезагрузка Windows может вернуть её; сообщи об ошибке с версией Windows и Пульса. Не используй старые версии для проверки удаления.

## Почему Windows пишет «Неизвестный издатель»?

Установщик пока не подписан доверенным сертификатом. Перенос установки в Program Files этого не меняет. Скачать официальный выпуск можно на [странице Releases](https://github.com/VP-code98/pulse-downloads/releases/latest); его SHA-256 опубликован там и в [SHA256SUMS.txt](../SHA256SUMS.txt).

Для проверки скачанного файла в PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "$env:USERPROFILE\Downloads\Pulse-Setup-0.13.6.exe"
```

Если файл сохранён в другую папку, укажи её. Сравни результат с контрольной суммой выпуска. Совпадение подтверждает соответствие опубликованному файлу, но не заменяет цифровую подпись издателя.

## Gmail уже доступен всем?

Нет. На 8 октября 2026 года бренд подтверждён, а доступ к `gmail.metadata` проходит проверку Google. До одобрения возможны предупреждение о непроверенном приложении и ограничения Google на подключение пользователей. Доступность массового входа будет объявлена после завершения проверки.

Пульс получает отправителя, тему, дату и служебные метки новых писем, без текста и вложений. Подробности — в [политике конфиденциальности](https://pulse-desktop.pp.ua/privacy).

## Должны ли работать Telegram Desktop и Viber Desktop?

Для Telegram — нет: Пульс использует собственную сессию. Для новых сообщений Viber Desktop должен оставаться запущенным. Его окно можно свернуть. После изменений в Viber совместимость может потребовать обновления Пульса.

## Почему уведомление сайта не появилось?

Проверь разрешения сайта, браузера и Windows. Сайт должен отправлять настоящее браузерное уведомление, дошедшее до центра уведомлений Windows. Старые уведомления после добавления сайта не загружаются. Пульс не извлекает сообщения из веб-страниц.

## Игровой режим включается в любой игре автоматически?

Автоматический режим сейчас отслеживает активную CS2. Для других игр включи режим вручную в раскрытом островке или настройках. Пауза почты и плеера настраивается отдельно; Telegram, Viber, таймер и напоминания продолжают работать. Изменение FPS не измерялось.

## Почему нет регулировки яркости?

Она доступна только для экранов, яркостью которых Windows позволяет управлять используемым способом. На неподдерживаемом экране регулятор может отсутствовать или быть недоступен. Скриншот другого компьютера не означает, что функция доступна на каждом устройстве.

## Как обновить или удалить приложение?

Для обновления заверши Пульс через его значок в трее и запусти новый официальный установщик. Настройки и подключения хранятся в пользовательском профиле отдельно от папки программы. Удаление выполняется обычным способом через список приложений Windows.

## Как сообщить об ошибке?

Открой [форму ошибки](https://github.com/VP-code98/pulse-downloads/issues/new?template=bug_report.yml), укажи версию Пульса и Windows, шаги и результат. Issues публичны: не прикладывай коды входа, пароли или личную переписку. Для частного обращения используй [poljukhvlad@icloud.com](mailto:poljukhvlad@icloud.com).
