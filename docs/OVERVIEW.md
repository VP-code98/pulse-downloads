# Пульс для Windows — текст для обзора

Пульс собирает рядом с тобой уведомления **конкретных разговоров**: личных чатов, групп, каналов и даже одной темы внутри группы Telegram. Выбирай, например, только тему «Релизы» в рабочей группе, личный чат друга и нужный канал. Другие темы этой группы в Пульсе не появятся. В Viber тоже отмечаются нужные чаты.

Как настроить: «Подключения» → Telegram → поиск названия → «Чат» → нужная тема в «Область наблюдения» → «Добавить источник» → «Сохранить выбранные источники». Для канала сначала подпишись на него в Telegram. Для Viber подключи Viber Desktop и отметь разговоры галочками.

Также в Пульсе есть музыка, таймер, календарь с напоминаниями, плавающий док и пункт управления. Интерфейс доступен на украинском, английском и русском. Бесплатная бета для Windows 10/11 x64. Gmail пока проходит проверку Google. Установщик пока не подписан.

## Українською

Пульс для Windows показує сповіщення **конкретних розмов, які обираєш ти**: особистих чатів, груп, каналів і навіть окремої теми в групі Telegram. Наприклад, обери лише тему «Релізи» у робочій групі, чат друга та потрібний канал. Решта тем цієї групи не з’являться в Пульсі. У Viber також можна позначити потрібні чати.

Налаштування: «Підключення» → Telegram → пошук назви → «Чат» → потрібна тема в «Область спостереження» → «Додати джерело» → «Зберегти вибрані джерела». Для каналу спочатку підпишись на нього в Telegram. Для Viber підключи Viber Desktop і познач розмови галочками.

Музика, таймер, календар із нагадуваннями та плаваючий док також поруч. Безкоштовна бета для Windows 10/11 x64. Доступ до Gmail ще проходить перевірку Google; інсталятор наразі не підписаний.

## In English

Pulse for Windows brings notifications from **specific conversations you choose** into a compact desktop island. Follow Telegram direct chats, groups, subscribed channels and even a single topic within a forum group. Choose your team’s Releases topic, a friend’s chat and a useful channel; other topics in that group stay out of Pulse. Viber chats can be selected too.

In settings: Connections → Telegram → search the name → Chat → choose a forum topic under Monitor messages from → Add source → Save selected sources. Subscribe to a channel in Telegram first. For Viber, connect Viber Desktop and check the conversations you want.

Pulse also provides music controls, a timer, calendar reminders and a floating app dock. Free beta for Windows 10/11 x64, with English, Ukrainian and Russian interfaces. Gmail access is still under Google review; the installer is currently unsigned.
